Install in three steps

Same employee experience on every OS.

  1. Install Windows: run install.ps1 from the zip. Mac: open .dmg → Applications. Linux: install the .deb.
  2. Sign in Use your esstracker username & password — no config files.
  3. Track esstracker stays in the tray and syncs to your company server.

Windows quick install

Expand the zip, then in that folder:
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Launch
# Start → esstracker → Sign in (tray icon in notification area)

Linux quick install

sudo apt install ./esstracker_*.deb
# then: Applications → esstracker → Sign in

The “unsandboxed as root / _apt” notice during install is harmless (same as DeskTime).

Tracking accuracy by platform

We researched how production trackers (DeskTime and others) ship clients — and the real limits of each OS. This is what to expect.

Windows

  • Active window via Win32 — generally reliable
  • Idle via last input tick — reliable
  • Screenshots need a normal desktop session (not locked RDP quirks)
  • Unsigned .exe may show SmartScreen — “More info → Run anyway”
  • Antivirus sometimes flags PyInstaller bundles (false positive)

macOS

  • Must live in /Applications
  • Accessibility permission required for window titles
  • Screen Recording required for screenshots
  • Without notarization, Gatekeeper blocks launch (“unidentified developer”)
  • Build Apple Silicon vs Intel separately (DeskTime does the same)

Linux

  • X11 + xdotool / xprintidle = best accuracy
  • Wayland often blocks window titles for sandboxed apps
  • GNOME needs AppIndicator extension for the tray icon
  • Install tray deps via apt (bundled in our .deb Depends)
  • Must run inside a graphical session (not SSH-only)
